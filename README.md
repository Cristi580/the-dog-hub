# The Dog Hub — Raw Dog Food E-Commerce Website

An SEO-optimized, responsive e-commerce website built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS** for **The Dog Hub**, a DEFRA-approved 80/10/10 raw dog food shop.

## Features

- **Mobile-Friendly Navigation Bar (`Navbar.tsx`)**: Sticky navigation with links for **Home** (`/`), **Products** (`/products`), **Shop** (`/shop`), and **Contact Us** (`/contact`), responsive mobile drawer menu, and a slide-over **Insulated Raw Box Cart** with free-shipping progress bar.
- **Earthy & Natural Design System**: Custom Tailwind color palette featuring warm forest greens (`forest`), terracotta accents (`terracotta`), cream backgrounds (`cream`), and dark charcoal typography (`Fraunces` serif + `Plus Jakarta Sans`).
- **Interactive Daily Portion Calculator (`FeedingCalculator.tsx`)**: Calculates daily raw food grams, weekly 500g packs, and estimated daily cost based on dog weight and activity/life stage.
- **Full Shop Catalog (`ShopCatalog.tsx`)**: Filter by category (80/10/10 Complete Meals, Starter Boxes, Raw Meaty Bones, Air-Dried Treats, Supplements), life stage, keyword search, and price sorting.
- **Comprehensive SEO**: Next.js Metadata API, OpenGraph & Twitter Cards, JSON-LD `PetStore` structured data, dynamic `sitemap.xml`, and `robots.txt`.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
